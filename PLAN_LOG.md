# PLAN_LOG

## Goal
Build a simple calculator app: a single-file web app (`index.html`, no dependencies, no build step).

## Plan
1. **Part 1 (this session):** `index.html` with the calculator UI shell (display, digit keys, operator keys) and the **add** feature working end to end (e.g. 2 + 3 = 5), including clear.

3. **Part 3:** Decimals, backspace, chained operations, and keyboard input.
4. **Part 4:** Polish: responsive layout, accessibility (labels, focus states), and basic manual test pass.
